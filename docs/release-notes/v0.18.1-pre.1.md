# WinMedic v0.18.1-pre.1

A preview, for trying one change before it is released: an introduction on
the first start. Everything else is v0.18.0.

---

## To try

- **An introduction on the first start:** three short pages before the
  window itself: what WinMedic does, the two buttons that do it (*Scan now*,
  then *Repair*), and what you can leave alone (Advanced mode, Settings).
  *Skip* is as big as *Next*, and `Esc` skips too.
- **Where to see it:** it opens by itself only on a PC that has no WinMedic
  settings and no saved scan. On any other PC, *Help -> Show the
  introduction* shows the same pages.

## Good to know

- **This is a pre-release.** WinMedic does not offer it as an update, and
  WinGet and Chocolatey do not carry it: download
  `winmedic-v0.18.1-pre.1.exe` from this page.
- **The next release replaces it.** Whoever runs this version is offered the
  next release as an update, as usual.
- **Nothing else differs from v0.18.0:** no check and no repair changes.
- **Tell us what you think** of the introduction:
  https://github.com/SecretLUL/WinMedic/issues
