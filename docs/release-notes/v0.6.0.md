# WinMedic v0.6.0

Healing Windows at 1 HP. This release finds broken devices and damaged
drivers, shows what changed before your PC started crashing, repairs Windows
from an ISO when Windows Update cannot — and stops a number of repairs from
claiming more than they did.

---

## New

- **Devices & Drivers:** devices that stopped or have no driver, restarted or
  looked up again and read back afterwards. When a group policy keeps drivers
  out of Windows Update, WinMedic names it.
- **What changed before the crashes:** after two or more crashes, the updates,
  new drivers and programs of the week before the first one, each with how to
  undo it.
- **Repair from an ISO:** when Windows Update cannot deliver the files DISM
  needs, WinMedic repairs from a Windows ISO in your Downloads folder, and
  says which one to download when there is none.
- **SFC** is read from what it wrote to CBS.log, not from its exit code, which
  is 0 whatever it found.

## Repairs that are honest now

- **DNS** is checked the same way in every display language. On French,
  Spanish, Italian … Windows it used to report a dead resolver on every scan.
- **Offline** no longer resets the network stack (that wiped static addresses
  and VPN entries). It tells you to check the router, cable or Wi-Fi.
- **Blue-screen dumps** are no longer deleted as a "repair"; that made the
  crash findings vanish. Dumps older than 30 days can still be cleaned up.
- **PCIe power saving, the memory test, driver crashes:** the power setting is
  really switched off and read back, the memory test is scheduled for the next
  restart instead of a dialog that was closed after five seconds, and driver
  crashes are advice instead of "fixed" by opening Device Manager.
- **Autostart entries** with `_` in their name are deleted.
- **Update cache, file system check, temp files, icon cache:** each step is
  checked, and the messages say what was actually freed.
- A company or school **proxy** that works is left alone.

## Safer

- The restart dialog never opens by itself, and only `Y` confirms a dialog.
- Emptying the Recycle Bin empties only your own.
- A declined UAC prompt no longer closes WinMedic.
- The background scan runs with administrator rights when you set it up as
  administrator, and a scan without them never replaces one with them.
- Reports carry only their own run's log, not the whole history.
- Protected scheduled tasks are left as they are.

## Also

- Easy mode fits on small screens with high scaling.
- A `config.json` saved with a byte order mark is read, not set aside.
