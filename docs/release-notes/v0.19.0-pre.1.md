# WinMedic v0.19.0-pre.1

A preview, for trying five changes before they are released: an
introduction on the first start, Settings in pages, and anonymous usage
data that is off until you agree. No check and no repair differs from
v0.18.0. It takes the place of v0.18.1-pre.1, whose introduction is in it.

---

## To try

- **An introduction on the first start:** three short pages before the
  window itself: what WinMedic does, the two buttons that do it (*Scan now*,
  then *Repair*), and what you can leave alone (Advanced mode, Settings).
  *Skip* is as big as *Next*, and `Esc` skips too. It opens by itself only
  on a PC that has no WinMedic settings and no saved scan. On any other PC,
  *Help -> Show the introduction* shows the same pages.
- **Settings, one page at a time:** the Settings view is five short pages
  now, picked from a list on the left: *Repairs*, *Undo changes*, *Scans*,
  *Logs* and *General*. A page shows a handful of things, so the small
  window of Easy mode is no longer filled with text, and each setting has
  one line of explanation. The arrow
  keys walk the settings and turn the page with them, `PgUp` and `PgDn` turn
  the pages, `B` goes to the registry backups and back. The page you pick
  comes in the way the two views do.
- **Anonymous usage data, only if you agree:** after the introduction of a
  first start WinMedic asks once whether to share it. It is off until you
  click *Yes, share*. With it on, the window sends a short report after each
  scan and each repair: the version, the Windows build number, the mode, how
  long the scan took, the health score, and for each check only numbers.
  Never names of devices, files or folders, your user or computer name, or
  the text of a finding.
- **Where to see it:** *Settings -> General -> Share anonymous usage data*.
  Ticking it opens the page that says what is sent and where it goes; *Show
  what is sent* shows a report before anything goes out. Every report that
  was sent is also written to `usage-data.log` in the log folder.
- **Where it goes:** to the developer's own server in Germany, by way of
  Cloudflare. Like every server, both see your IP address. The developer's
  server does not write it down and does not pass it on to the statistics.
- **A long scan says that all is well:** a scan that runs longer than half a
  minute now says so, and which check it is still waiting for. The bar
  reaches 99 % within seconds and then waits for the slowest check.

## Good to know

- **This is a pre-release.** WinMedic does not offer it as an update, and
  WinGet and Chocolatey do not carry it: download
  `winmedic-v0.19.0-pre.1.exe` from this page.
- **The next release replaces it.** Whoever runs this version is offered the
  next release as an update, as usual.
- **Nobody is asked twice, and nobody who already uses WinMedic is asked at
  all:** the question comes only after the introduction of a first start.
  For everyone else the switch under *Settings -> General* stays off until
  they tick it.
- **`--scan`, `--auto-fix` and the background scan send nothing,** whatever
  the switch says.
- **Tell us what you think,** of the introduction, the new Settings and the
  question about usage data: https://github.com/SecretLUL/WinMedic/issues
