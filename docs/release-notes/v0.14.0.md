# WinMedic v0.14.0

Measure twice, cut once. A review of the whole program ends some fifty cases
in which a finding blamed something that works, a repair did more than you had
ticked, or a message guessed at its reason. Two things are new: a disabled
device that keeps a service from starting can be enabled, and Windows' own
tasks that old versions switched off can be switched back on.

---

## New

- **A disabled device behind a stopped service:** when a service cannot start
  because the device its driver serves is disabled, WinMedic could enable only
  three Windows system devices; for any other it said "Device Manager ->
  Enable device". It now enables that device too, after backing up its
  setting. The repair starts unticked: leave it so if you disabled the device
  on purpose.
- **Windows' own tasks, switched back on:** up to 0.9.0 the only repair for a
  failing scheduled task was to switch it off, Windows' own included. The scan
  now names each task of Windows that is off and that WinMedic's own history
  shows it switched off, with the date, and Repair switches it on again. A
  task you switched off yourself is left alone.

## Repairs do what you ticked

- **Ticks you did not set:** a finding that starts unticked on purpose came
  back ticked once it had been repaired once. The Recycle Bin, emptied through
  WinMedic, was ticked again at the next scan, and Easy mode's Repair emptied
  it unasked.
- **Ticks changed while repairs ran** changed only the list on screen: a
  finding unticked during the run was repaired anyway. The tick boxes are
  greyed out until the run ends.
- **A setting changed during a scan or repair** showed "Setting saved" and
  took effect only after another change or a restart of WinMedic. "Back up
  the registry before changing it", switched on during a scan, did not hold
  for the next repair.
- **A cancelled cleanup** went on deleting to the end of every folder while
  the window said "Repair cancelled by the user". It stops after the file in
  hand.
- **Stray keys:** on the Settings page, **A** ticked every repairable finding
  and **N** unticked them all, unseen. An **Esc** that only closed a drop-down
  or left the search box also cancelled the running scan or repair.
- **Restore points:** `--auto-fix` with nothing to repair still created a
  restore point at every run, pushing older ones out. And when creating one
  ran out of time, Windows' once-a-day limit for restore points stayed
  switched off for good. Both are fixed.
- **A task whose program is back:** a finding from a saved scan, hours or
  days old, still had the task of a program switched off that had been
  reinstalled since. The repair looks again first.
- **Updates of WinMedic:** a download whose signature Windows does not trust
  was installed as "signature not checked". It is refused now.
- **Crash reports** promise to replace your user name, your computer's name
  and your user folder. One letter such as the Turkish "İ" anywhere in the
  log left all three in the report.

## Findings that blamed what works

- **Autostart entries and tasks of working programs** were reported as
  "points at a deleted program", ticked, and removed or switched off by
  Repair: a task of another account such as OneDrive's updater, a program on
  a drive BitLocker had not unlocked yet, and commands without quotes, among
  them a program in a user folder like `john.exeter` and one named without
  `.exe`.
- **"This PC is unprotected against malware"** was raised as critical, with
  Defender or another antivirus running, when Windows Security did not answer
  the question.
- **Work PCs joined to Entra ID:** their update policies were reported as
  damage by a tweak tool, and a repair deleted values the management puts
  back. They are left to their administrators, as a domain's already were.
- **"The Winsock catalog is damaged"** was raised for a component that ships
  only a 32-bit file. The offered reset would have removed it, and the
  components of every VPN and security program with it.
- **Scanning while offline:** with the router off, "The proxy set for this
  user does not answer" was ticked, and Repair switched off the proxy a school
  or company network needs. Behind a Hyper-V switch or a network bridge, an
  adapter switched off on purpose became a ticked "this PC has no network".
  And a DNS test that could not run at all counted as "DNS name resolution
  failed".
- **Windows Update:** error `0x80070103` says that the driver offered is
  already installed. It was answered with a reset of the update components,
  which erases the update history and changes nothing. Each reset also left
  the old download cache behind, possibly gigabytes; the next reset now
  removes it and says so.
- **Page file:** a small fixed page file on C: beside a large one on D: was
  flagged as undersized. "Page file on a nearly full drive" was raised for a
  2 TB drive with 180 GB free. And the repair could report "handed back to
  Windows" with nothing changed; it now reads back what it set.
- **SFC:** a `sfc /scannow` that stopped midway was reported as "left none
  damaged". On a Russian, Greek, Chinese, Japanese or Korean Windows the
  repair log showed empty lines for the 10 to 30 minutes SFC takes.
- **Drives:** archiving the SMART warning of one disk hid every later one,
  the system drive's included; each disk has its own finding now. Where
  Windows is not on C:, the disk check and the crash dumps looked at the
  wrong drive.
- **Crashes:** a PC that logs PCIe errors many times a minute hid its memory
  and processor errors behind them. A crash in one program's Explorer add-on
  blamed every add-on with the same file name, Defender's among them, and the
  warning stayed for 30 days after the add-on had been updated. On Windows 10
  and some Windows 11 PCs such crashes were not found at all.
- **The repair from a Windows ISO** said the image held no edition for this
  PC on Windows 10 1809 to 2004, LTSC 2019 included.
- **"Frees about"** counted programs' old crash dumps twice.

## The window

- **Chinese, Japanese, Korean, Thai and Indic text** was drawn as empty
  boxes: device names, task names, paths under your user folder. It is drawn
  with Windows' own fonts now.
- **In a low window,** such as a 1080p screen at 175 %, the open log covered
  the list of findings.
- **Keyboard:** the lists follow the row the arrow keys moved to. **Enter**
  on a number setting opens its dialog instead of saving unseen. A held
  **F7** no longer flips the mode thirty times a second.
- **Window size:** moved from a laptop screen at 200 % to a monitor at 100 %,
  the window's smallest size was taller than the monitor. And after a quit in
  Easy mode, Advanced mode opened at Easy mode's size instead of yours.
- **A graphics driver that fails at start** left no window and no message.
  WinMedic now says that it could not open its window.

## Command line and background scan

- **Exit codes:** a mistyped option ended with 2, which means "open critical
  issues". It ends with 8 now, and nothing is run. A report that could not be
  written ends with 5 instead of looking like success. A scan cancelled with
  Ctrl+C no longer writes its half report over the last complete one.
- **A damaged `config.json`** met first by the background scan was moved
  aside without a word, and the window started with default settings. It is
  left for the window, which says so.
- **The background scan after an update:** in a folder with a name such as
  "Büro", the scheduled task kept starting the old file, which the next start
  deletes. The scan was dead until the setting was switched off and on.
- **Logs:** while another program held the log open, each new entry deleted
  one older log file until all five were gone. And one damaged line hid every
  later entry from "Recent activity" and from reports.

## Also

- A simulation marks the steps left to you with "By hand:" and no longer
  counts them among the steps that would run.
- Clearing the print queue is rated as medium risk, not low: it restarts the
  print spooler.
- The clock repair says what Windows' time service answered instead of
  guessing why the clock is still off.
