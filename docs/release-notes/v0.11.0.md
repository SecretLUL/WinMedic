# WinMedic v0.11.0

House calls for the sickest PCs. The window draws with Direct3D 12 now, so a
crashed graphics driver, a virtual machine or a broken OpenGL driver no longer
keeps it shut. A new check finds why OpenGL games stop starting while
everything else works, and a WinSxS cleanup with nothing to remove no longer
counts as a failed repair.

---

## New

- **The window draws with Direct3D 12** instead of OpenGL: through the
  graphics card where its driver offers it, and with Windows' own software
  renderer (WARP) where none does, slower but complete. That covers the
  Microsoft Basic Display Adapter after a driver crash, virtual machines,
  remote sessions and a PC whose OpenGL driver is gone, where 0.10.2 said
  "WinMedic could not open its window". That message is left for Direct3D 12
  failing in software too, which usually means damaged system files. The
  download is about 3 MB larger.
- **A graphics card whose OpenGL driver Windows cannot find:** when a card's
  driver key names an OpenGL driver file that is gone, OpenGL games and
  programs, Minecraft among them, get only Windows' own OpenGL 1.1, and most
  do not start. Direct3D goes on working, and Device Manager shows nothing. A
  driver Windows Update installs for a second graphics adapter can leave a
  card like this. WinMedic points the entry back at the file of the same name
  beside the card's Direct3D driver, backs up each entry first and reads it
  back. The repair starts unticked, and Windows takes the new entry only after
  a restart. Without that file, the finding says to install the graphics
  driver again.

## Fixed

- **A WinSxS cleanup with nothing to remove** counted as a failed repair
  since 0.10.0: "Repair failed" in red, "1 repair did not work" in Easy mode,
  exit code 3 after `--auto-fix`. DISM counts packages the cleanup never removes, such as
  the 24H2 checkpoint update. Such a finding now says "Nothing to remove" and
  counts as done.

## Safer

- **The window's graphics settings are WinMedic's own:** no `WGPU_*`
  environment variable changes which graphics API or adapter it uses or which
  DLLs it loads.
