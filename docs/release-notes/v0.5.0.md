# WinMedic v0.5.0

Healing Windows at 1 HP. This release is about making WinMedic easy for
everyone: a new Easy mode, a plain window with a new logo, checks that finally
work on every Windows, and new checks for the problems that make a PC only
half work.

---

## Easy mode

WinMedic now opens in **Easy mode**: how your PC is doing, what *Repair* will
do, and two big buttons.

- *What Repair does* is a short forecast built only from what the scan
  measured: "Frees about 8.4 GB of disk space", "Windows Update works again",
  "Health goes up to about 76 / 100". Repairs that only record a finding
  promise nothing.
- The window stays at its smallest size, 960 × 640, and cannot be resized in
  Easy mode.
- **F7**, or the button next to *Export report*, switches to **Advanced mode**:
  every finding with its details, filters, the logs and the simulation. The
  window is resizable there again, and WinMedic remembers the mode.

If you used WinMedic before, it opens in Easy mode once; F7 takes you back.

## A plain window and a new logo

- One *Scan & Repair* page instead of five tabs, and *Settings* for everything
  else. Windows' own light and dark look, Segoe UI.
- A new logo — a green shield with a cross — as the app icon, in the window and
  in the HTML report.
- A README that fits on a few screens; the technical detail lives in
  [How WinMedic works](https://github.com/SecretLUL/WinMedic/blob/main/docs/how-it-works.md).

## Checks that work on real Windows

Several checks could never fire, on any machine: `wevtutil` rejected every
event log query, crash analysis asked the wrong provider, the service check
looked for a start type `sc query` never prints, and German DISM output never
matched. All of them are fixed, read language-neutral sources where Windows
offers one, and are tested against output captured from real Windows. CI now
runs a real scan on every change.

## New checks

- **Tweaks & Policies:** core services switched off by tweak tools, Windows
  Update and Store blocked by policy, hosts entries that block Windows.
- **System:** Windows Recovery Environment switched off, WMI that does not
  answer, the result of the last Windows Memory Diagnostic.
- **Network:** an adapter stuck on a 169.254 address, a WinHTTP proxy nothing
  answers at.
- **Clock & Restart:** a clock that is off, and weeks without a real restart
  (Fast Startup "shutdowns" do not count).

## Background scan and Start with Windows

Two optional settings: *WinMedicHelper* scans in the background on a schedule,
and WinMedic can start with Windows. `winmedic --uninstall` removes both before
you delete the file. WinMedic no longer needs `VCRUNTIME140.dll`.

## Also

- WinGet gets new releases again: v0.4.0 and v0.4.1 never reached
  `winget install SecretLUL.WinMedic`, this one does.
- The number keys are `1` and `2` for the two views.
